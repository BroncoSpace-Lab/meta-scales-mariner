This layer is for the custom Hardware for the SCALES system and uses a minimal configuration of the Phytec i.MX 8X SOM.

This layer was created by following the following [BRONCO SPACE NOTION](https://broncospace.notion.site/Creating-a-Custom-Yocto-BSP-28cca1dca64c8002a145c9d9d180d923) guide created by John Pollak with help from Phytec Support members Garrett Giordano and True Loan. 
This guide is a comprehensive version of the working process that John Pollak and Luca Lanzillotta did to achieve a stable and working Yocto Linux image.

For more information on the SCALES project please visit our [SCALES Documentation Site.](https://scales-docs.readthedocs.io/en/latest/)
